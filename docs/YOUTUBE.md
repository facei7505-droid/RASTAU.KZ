**Название**

Rastau: акимат платит за факт, а не за бумагу | G-TON 2026

**Описание**

Rastau проверяет работу подрядчиков по фото с места: GPS, время, повтор снимка и сравнение «до/после» проверяет сервер, решение принимает человек, акт подписывается ЭЦП. Акимат платит только за подтверждённое.

Проект для акселератора G-TON 2026, задачи:
• №2 Конаев: единая карта 127 строек
• А-3 область Абай: контроль дорог
• №6 Конаев: подтверждение вывоза мусора
