# Rastau: техническое описание

> Рабочее название продукта: Rastau (каз. «растау» — подтверждать). Внутренние имена таблиц и функций остаются с префиксом `fakt_`.

Веб-приложение (PWA) для задач G-TON: №2 Конаев (карта 127 строек), А-3 область Абай (дороги), №6 Конаев (вывоз ТКО).
Работа подрядчика засчитывается только по фото с места, проверенному сервером: камера приложения, GPS и расстояние до точки,
время сервера, уникальность снимка по всей базе, сравнение «до/после».

## Стек
- Фронтенд без сборки: Preact + htm + Leaflet, ES-модули из `src/` (в продакшене библиотеки с jsDelivr, версии закреплены).
- Бэкенд: Supabase (PostgreSQL, Auth, Storage, Realtime). Баллы доверия считает триггер `fakt_evidence_verify` на сервере.
- Журнал действий с цепочкой хэшей, писать в него можно только из триггеров.
- Хостинг: Vercel, статические файлы.

## Запуск локально
```
npm install
python3 -m http.server 5175   # из корня проекта
```
На `127.0.0.1` приложение работает офлайн с демо-данными в IndexedDB (см. `window.FAKT_LOCAL` в `index.html`).

## Что есть
- Руководитель: карта всех объектов, флаги, цели G-TON, рейтинг подрядчиков, сводка для акима (PDF, CSV, JSON), справочники
  (объекты с картой, импорт реестра из Excel/CSV, подрядчики, пользователи, нормативы, QR-таблички).
- Инспектор: фиксация дефекта и заявка подрядчику, объезд с GPS-треком, приёмка «до/после», акт с подписью ЭЦП (NCALayer).
- Подрядчик/перевозчик (рус/қаз): задания, фото-доказательства, жалобы жителей с таймером норматива, маршрут по срочным площадкам.
- Житель (рус/қаз, без регистрации): QR на объекте → карточка объекта → обращение → статус по короткому номеру.
- Гарантия 12 мес. (повторный дефект в 50 м от принятого ремонта — за счёт подрядчика), оценка неустойки, санитарная норма вывоза
  ТКО по температуре воздуха.
- Без связи: фото сохраняются в очередь на телефоне и уходят на сервер при появлении сети (сервер видит задержку `delay_ms`),
  последние данные кэшируются, оболочка приложения работает через service worker.
- Персональные данные: лица и номера закрываются на телефоне до отправки (MediaPipe на устройстве + ручная маскировка касанием).

## Дизайн 2.0 и план пилота (12.10.2026)
- Логотип: тёмно-синий квадрат, белая метка места и золотая галочка (`favicon.svg`, `src/ui/icons.js`: `Logo`, `Wordmark`).
  Иконки в стиле Lucide вместо эмодзи, шрифт Inter (локально из `fonts/`, на сайте с jsDelivr, `@fontsource-variable/inter@5.3.0`).
- Вход: шесть сценариев для жюри списком, плитки ролей, ссылка на план пилота. Навигация с иконками, на телефоне нижняя панель.
- Страница `#/pilot` (`src/ui/pilot.js`, рус/қаз): цели акимата по задачам №2, А-3, №6, план на 8 недель с метрикой к каждому
  бордмитингу, что нужно от акимата, соответствие законам РК. Ссылка с экрана входа и из блока «Цели задач G-TON».
- Кэш service worker: `rastau-v8`.

## База
Схема: `supabase/schema.sql`, изменения: `supabase/migrations/`. Edge-функции: `fakt-seed` (одноразовая заливка демо),
`fakt-admin` (создание пользователей руководителем).

## Выкладка
`deploy/` собирается скриптом минификации по файлам (структура `src/` сохраняется) и выкладывается на Vercel.
